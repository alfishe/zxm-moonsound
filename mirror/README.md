# ZXM-MoonSound Mirror

Archived mirror of the original ZXM-MoonSound page from [micklab.ru](http://micklab.ru/My%20Soundcard/ZXMMoonSound.htm).

## Files

- `index_ru.html` - Original Russian page with fixed relative links
- `index_en.html` - English translation with same design
- `gre/` - Graphics and UI elements
- `file/zxm_moonsound/` - All downloadable content:
  - `*.rar` - Hardware files (schematics, PCB, firmware)
  - `*.pdf` - Documentation
  - `img/` - Board photos
  - `soft/` - Software (demos, service tools)
    - `img/` - Demo screenshots

## Purpose

This mirror preserves the ZXM-MoonSound documentation and files for historical purposes, ensuring they remain accessible even if the original site becomes unavailable.
