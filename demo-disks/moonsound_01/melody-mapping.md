# Moonsound Demo (Original) - Info

Source: `moonsound_demo.asm`

## Overview

This is the **original MoonSound driver demo** from 2015. It demonstrates the MoonBlaster Wave driver but does not contain standalone MWM music files.

## Contents

- `moon_driver.asm` - MoonBlaster Wave player driver
- `O3D001.MDR`, `O3D002.MDR` - Wave sample data (ROM images)
- `moonsound_demo.asm` - Demo shell

## Notes

- First release demonstrating ZXM-MoonSound driver capabilities
- Wave samples embedded in MDR format, not playable MWM files
- Foundation for later demos which include actual music tracks
